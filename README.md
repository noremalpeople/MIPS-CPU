# MIPS 多周期 CPU

基于 Verilog 实现的 MIPS 多周期处理器，支持 30 条 MIPS 指令，采用有限状态机控制，适配 N4 开发板 (Artix-7 FPGA)。

## 项目简介

本项目实现了一个完整的 MIPS 多周期 CPU，包含取指(IF)、译码(ID)、执行(EXE)、访存(MEM)、写回(WB)五个阶段。CPU 通过有限状态机控制各阶段的执行顺序，每条指令需要多个时钟周期完成。

## CPU 架构

### 数据通路
```
                    ┌─────────────┐
                    │  ControlUnit│
                    └──────┬──────┘
                           │ 控制信号
    ┌──────────────────────┼──────────────────────┐
    │                      │                      │
    ▼                      ▼                      ▼
┌───────┐   ┌───────┐   ┌───────┐   ┌───────┐   ┌───────┐
│  PC   │──▶│  ROM  │──▶│  IR   │──▶│ Split │──▶│Extend │
└───────┘   └───────┘   └───────┘   └───────┘   └───────┘
    │                                           │
    │         ┌───────┐   ┌───────┐             │
    └────────▶│PC_next│   │RegFile│◀────────────┘
              └───────┘   └───┬───┘
                              │
                          ┌───▼───┐
                          │  ALU  │
                          └───┬───┘
                              │
                          ┌───▼───┐
                          │  RAM  │
                          └───────┘
```

### 状态机
```
INIT → IF → ID → EXE → MEM → WB
         ↑                   │
         └───────────────────┘
```

状态说明:
- **INIT**: 初始化状态
- **IF**: 取指阶段 (Instruction Fetch)
- **ID**: 译码阶段 (Instruction Decode)
- **EXE**: 执行阶段 (Execute)
- **MEM**: 访存阶段 (Memory Access)
- **WB**: 写回阶段 (Write Back)

## 使用方法

### 环境要求
- Xilinx Vivado 2021.2 或更高版本
- N4 开发板 (Artix-7 xc7a100tcsg324-1)

### 仿真步骤
1. 打开 Vivado，加载工程文件 `MIPS CPU.xpr`
2. 确保 `inst.txt` 文件在工程目录下
3. 运行行为仿真 (Run Behavioral Simulation)
4. 观察波形，验证 CPU 功能

### 下板验证
1. 综合 (Synthesis) -> 实现 (Implementation) -> 生成比特流 (Generate Bitstream)
2. 连接 N4 开发板，下载比特流文件
3. 按 BTNU 复位 CPU
4. 通过开关选择显示内容，观察 LED 和数码管

### 显示内容选择 (通过开关 SW[3:0])
| 开关值 | 显示内容 |
|--------|----------|
| 0x0 | 当前 PC |
| 0x1 | 下一 PC |
| 0x2 | 当前指令 |
| 0x3 | IR 中的指令 |
| 0x4 | 寄存器 A |
| 0x5 | 寄存器 B |
| 0x6 | ALU 结果 |
| 0x7 | 数据总线 |
| 0x8 | 扩展后的立即数 |
| 0x9 | 状态机状态 |
| 0xA | 操作码和功能码 |
| 0xB | 寄存器地址 |
| 0xC | 控制信号 |

### 添加指令
1. 在 `ControlUnit.v` 中添加指令判断逻辑
2. 在状态机中添加对应的状态转移
3. 在 ALU 中添加对应的运算（如需要）
4. 更新 `inst.txt` 添加测试指令

## 指令文件格式

`inst.txt` 使用十六进制格式，每行一个字节，按大端序排列：

```
// 示例: add $1, $2, $3 (0x00430820)
00
43
08
20
```

## 设计特点

- **模块化设计**: 各功能模块独立，便于维护和扩展
- **清晰的注释**: 每个模块都有详细的中文注释说明
- **完整的指令集**: 支持 30 条常用 MIPS 指令
- **调试友好**: 丰富的调试输出信号，便于波形分析
- **板级适配**: 适配 N4 开发板，提供直观的硬件验证
